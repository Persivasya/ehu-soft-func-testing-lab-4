Тут представлен список разного рода артефактов, чтобы на них можно было ссылаться в тестовых кейсах.

## Базовое состояние

На момент начала какого-либо теста предполагается, что начальное состояние следующие: приложение запущено, окно "FileSearcher" открыто, язык интерфейса English, поле "Where to search" пусто, в списке "What to search" выбрано "Please, select...", таблица результатов пуста, "Items found: 0". Далее это состояние будет упоминаться как `БС` (Базовое состояние).

## Идентефикаторы требований 

| ID      | Требование                                                                                             |
| ------- | ------------------------------------------------------------------------------------------------------ |
| REQ-01  | Указание начального каталога в поле "Where to search"                                                  |
| REQ-02  | Выбор типа файлов в поле "What to search", набор типов строго фиксирован                               |
| REQ-03  | Запуск поиска кнопкой "Search", вывод результатов и счётчика "Items found"                             |
| REQ-04  | Аудиофайлы: mp3, ogg, wav, mid                                                                         |
| REQ-05  | Видеофайлы: avi, mpg, mpeg                                                                             |
| REQ-06  | Офисные файлы: doc, docx, xls, xlsx                                                                    |
| REQ-07  | Для каждого найденного файла отображается номер (1, 2, 3, ...)                                         |
| REQ-08  | Имя файла отображается с расширением                                                                   |
| REQ-09  | Полный путь отображается без имени файла                                                               |
| REQ-10  | Размер отображается с автоподбором единиц измерения                                                    |
| REQ-11  | Дата-время создания в формате YYYY-MM-DD HH:II:SS                                                      |
| REQ-12  | Для видеофайлов при наведении на имя отображается миниатюра первого кадра не более 100×100 пикселей    |
| REQ-13  | Для офисных и аудиофайлов при наведении на имя новые элементы интерфейса не отображаются               |
| REQ-14  | Глубина сканирования не ограничивается приложением                                                     |
| REQ-15  | Интерфейс на русском и английском языках, переключение между ними                                      |
| REQ-16  | Поиск в локальной сети по протоколу SMB                                                                |
| REQ-17  | Только стандартные библиотеки Java, сторонние запрещены                                                |
| REQ-18  | Среднее время задания критериев и анализа результатов минимум на 50 % меньше, чем в Проводнике Windows |
| REQ-19  | Работа в Windows 10 и Windows 11                                                                       |
| REQ-20  | Приложение написано на Java, компиляция JDK 21                                                         |
| RISK-01 | Риск: сложность анализа видеофайлов                                                                    |
| RISK-02 | Риск: низкая стабильность при работе с сетевыми дисками и каталогами                                   |

## Тестовые данные

Гипотетический набор тестовых данных.

| Набор | Каталог    | Содержимое                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ТД-1  | `flat`     | аудио: `track01.mp3`, `track02.ogg`, `track03.wav`, `track04.mid`, видео: `clip01.avi` (красный кадр), `clip02.mpg` (зелёный), `clip03.mpeg` (синий), 640×480, 3 с (создаются `ffmpeg`), офис: `doc01.doc`, `doc02.docx`, `sheet01.xls`, `sheet02.xlsx`, посторонние: `note.txt`, `movie.mp4`, `photo.jpg`, `song.flac`, `report.pdf`, `slides.pptx`, `clip.mkv`, `archive.zip`. Размер каждого файла 1024 байта, кроме видео |
| ТД-2  | `sizes`    | `s0.wav` (0 Б), `s500.wav` (500 Б), `s50k.wav` (51 200 Б), `s2m.wav` (2 097 152 Б)                                                                                                                                                                                                                                                                                                                                            |
| ТД-3  | `nested`   | `n1.mp3`, `level1\n2.mp3`, `level1\level2\n3.mp3`, `level1\level2\level3\n4.mp3`                                                                                                                                                                                                                                                                                                                                              |

| ТД-6  | `broken`   | `zero.avi` (0 Б), `corrupt.mpg` (1024 случайных байта)                                                                                                                                                                                                                                                                                                                                                                        |
| ТД-7  | `bulk`     | 10 000 файлов в 100 каталогах: по 2500 файлов `.mp3`, `.docx`, `.avi`, `.txt`                                                                                                                                                                                                                                                                                                                                                 |
| ТД-8  | SMB-ресурс | копия ТД-1 в сетевой папке `\\<сервер>\fsr_share`, доступной на чтение                                                                                                                                                                                                                                                                                                                                                        |
