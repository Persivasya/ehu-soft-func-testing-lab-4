## TC-020

| Поле          | Значение                                |
| ------------- | --------------------------------------- |
| Идентификатор | TC-020                                  |
| Модуль        | Сканер файловой системы                 |
| Подмодуль     | Обход каталогов                         |
| Заголовок     | Файл на глубине 100 вложенных каталогов |
| Требование    | REQ-14                                  |
| Предусловия   | БС. Каталог `C:\FSR_TEST\deep` (ТД-4)   |


| №   | Шаги                                                                                          | Ожидаемые результаты                                                                        |
| --- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1   | Ввести в поле "Where to search" значение `C:\FSR_TEST\deep`, выбрать "Audio", нажать "Search" | В таблице 1 строка с именем `deep.mp3`, "Items found" равно 1                               |
| 2   | Рассмотреть значение "Path" этой строки                                                       | "Path" равно `C:\FSR_TEST\deep` + 100 повторений `\d` (количество вхождений `\d` равно 100) |

## TC-021

| Поле          | Значение                                                                         |
| ------------- | -------------------------------------------------------------------------------- |
| Идентификатор | TC-021                                                                           |
| Модуль        | Приложение                                                                       |
| Подмодуль     | Производительность                                                               |
| Заголовок     | Среднее время задания критериев и анализа результатов по сравнению с Проводником |
| Требование    | REQ-18                                                                           |
| Предусловия   | БС. Каталог `C:\FSR_TEST\bulk` (ТД-7)                                            |


| №   | Шаги                                                                                                                                                             | Ожидаемые результаты                                  |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 1   | Выбрать "Audio", нажать "Search". Измерить время за которое "Search" завершился.                                                                                 | Получено время T1 затраченное на поиск                |
| 2   | Выполнить 1-й пункт 10 раз подряд (перед каждым повтором закрыть и заново открыть приложение)                                                                    | Получено 10 значений времени T1 затраченного на поиск |
| 3   | Выполнить задачу в Проводнике 10 раз подряд (в строку поиска Проводника вводить `*.mp3 OR *.ogg OR *.wav OR *.mid`, перед каждым повтором очищать строку поиска) | Получено 10 значений времени T2 затраченного на поиск |
| 4   | Вычислить средние арифметические T1 и T2                                                                                                                         | Среднее T1 не превышает 50 % среднего T2              |
