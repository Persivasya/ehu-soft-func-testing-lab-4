## TC-013

| Поле          | Значение                                |
| ------------- | --------------------------------------- |
| Идентификатор | TC-013                                  |
| Модуль        | Панель поиска                           |
| Подмодуль     | Поле "Where to search"                  |
| Заголовок     | Поиск при пустом поле "Where to search" |
| Требование    | REQ-01, REQ-03                          |
| Предусловия   | БС                                      |


| № | Шаги | Ожидаемые результаты                                                                                                                     |
| --- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | Выбрать в списке "What to search" пункт "Audio" | В списке отображается "Audio", поле "Where to search" пусто                                                                              |
| 2 | Нажать кнопку "Search" | Приложение не завершает работу, окно отвечает на действия (меню "Language" раскрывается по щелчку), таблица пуста, "Items found" равно 0 |
