## TC-008

| Поле          | Значение                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------ |
| Идентификатор | TC-008                                                                                           |
| Модуль        | Таблица результатов                                                                              |
| Подмодуль     | Столбцы                                                                                          |
| Заголовок     | Формат и значение даты-времени создания в столбце "DateTime"                                     |
| Требование    | REQ-11                                                                                           |
| Предусловия   | БС. Системные часы Windows настроены на текущее время. Файл создан непосредственно перед тестом. |


| №   | Шаги                                                                                          | Ожидаемые результаты                                                                                                   |
| --- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 1   | Ввести в поле "Where to search" значение `C:\FSR_TEST\date`, выбрать "Audio", нажать "Search" | В таблице отображается 1 строка с именем `created.mp3`                                                                 |
| 2   | Рассмотреть значение "DateTime" строки `created.mp3`                                          | Значение соответствует регулярному выражению `^\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}$` (например, `2026-11-18 14:07:05`) |
| 3   | Сравнить значение "DateTime" с системными параметрами                                         | Значение "DateTime"  идентично значению содержащемуся в метаданных файла                                               |
