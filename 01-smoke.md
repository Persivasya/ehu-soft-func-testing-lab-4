## TC-001

| Поле          | Значение                                                |
| ------------- | ------------------------------------------------------- |
| Идентификатор | TC-001                                                  |
| Модуль        | Панель поиска                                           |
| Подмодуль     | Кнопка "Search"                                         |
| Заголовок     | Поиск типа Audio в каталоге со смешанными типами файлов |
| Требование    | REQ-04, REQ-03                                          |
| Предусловия   | БС. Каталог `C:\FSR_TEST\flat` (ТД-1)                   |


| № | Шаги | Ожидаемые результаты                                                                                                                                                          |
| --- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | Ввести в поле "Where to search" значение `C:\FSR_TEST\flat` | В поле отображается `C:\FSR_TEST\flat`                                                                                                                                        |
| 2 | Выбрать в списке "What to search" пункт "Audio" | В списке отображается выбранный пункт "Audio"                                                                                                                                 |
| 3 | Нажать кнопку "Search" | В таблице отображаются ровно 4 строки с именами `track01.mp3`, `track02.ogg`, `track03.wav`, `track04.mid`, значение "Items found" равно 4, файлов других типов в таблице нет |

## TC-004

| Поле          | Значение                                                                                                                                                                                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор | TC-004                                                                                                                                                                                                                                                                                       |
| Модуль        | Приложение                                                                                                                                                                                                                                                                                   |
| Подмодуль     | Запуск                                                                                                                                                                                                                                                                                       |
| Заголовок     | Запуск и поиск типа Audio в Windows 10 и в Windows 11                                                                                                                                                                                                                                        |
| Требование    | REQ-19                                                                                                                                                                                                                                                                                       |
| Предусловия   | Две виртуальные машины: Windows 10 и Windows 11 (64-разрядные). На каждой машине скопированы есть `file_searcher.exe` и `settings.set` в одном каталоге и зашружен ТД-1. Приложение не запущено. Шаги выполняются на каждой виртуальной машине, результат фиксируется отдельно для каждой ОС |


| №   | Шаги                                                                                                                           | Ожидаемые результаты                                                                                                                                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Запустить `file_searcher.exe`                                                                                                  | Открывается окно "FileSearcher" с полем "Where to search", списком "What to search", кнопкой "Search", надписью "Items found: 0" и пустой таблицей со столбцами "#", "Name", "Path", "Size", "DateTime" |
| 2   | Ввести в поле "Where to search" значение `C:\FSR_TEST\flat`, выбрать "Audio" в списке "What to search", нажать кнопку "Search" | В таблице отображаются 4 строки (`track01.mp3`, `track02.ogg`, `track03.wav`, `track04.mid`), "Items found" равно 4                                                                                     |
| 3   | Выбрать пункт меню "Main" - "Exit"                                                                                             | Окно приложения закрывается, процесс `file_searcher.exe` отсутствует в списке процессов Диспетчера задач                                                                                                |
